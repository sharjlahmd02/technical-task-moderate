
## What I am building
A single webpage where to view, add, edit, and delete customer records, like a basic **CRM**.

## Current Progress 
For now I just strutured the react app basic folder.

## Tech Stack
* ReactJS for frontend
* Chakra UI as UI Library
* Hasura as the backend and Neon as database (Postgre)
* Apollo client to communicate between ReactJS and Hasura
